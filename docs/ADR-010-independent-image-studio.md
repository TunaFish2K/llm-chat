# ADR-010：独立绘图工作区

状态：已采纳。

## 决策

侧栏提供独立绘图工作区入口（欢迎页不再放置入口）。进入后使用单独的 `/images` 路由和导航，不创建或复用聊天会话；生成记录以聊天消息的形式排列（提示词气泡与结果回复），发送栏、模型选择、参数弹层和操作栏复用聊天组件。绘图工作区直接列出已启用、连接可用且声明图片输出协议的模型，不受聊天图片工具目录开关影响。

绘图会话保存标题、当前草稿和参考图片资产。每次新生成创建一个时间线节点；重试、重新生成与编辑提示词都在原节点增加版本（编辑对应聊天的“编辑并分叉”，沿用原模型和参数），节点保存当前选中版本。输出图片加入会话资产，可下载或作为后续参考图。删除运行中的版本、节点或会话前必须先取消任务。

图片任务使用同一张任务表，但归属互斥：任务要么属于聊天会话及助手消息，要么属于绘图会话及时间线节点。数据库约束禁止同时归属或无归属。聊天输出继续挂到消息；绘图输出挂到绘图会话，不写入消息历史或模型上下文。

服务端按图片协议发布能力，包括生成、参考图编辑、图片数量、比例、尺寸、质量、格式、负面提示词和随机种子。客户端只展示可用参数，服务端再次校验操作、参考图数量和批量数量。首个版本仅支持文生图和参考图编辑。

## 后果

- 绘图历史不会污染聊天搜索、离线消息和对话上下文。
- 模型连接的停用或删除会使后续任务失败，但已有绘图记录和输出仍可读取。
- 绘图会话列表和任务事件需要独立同步；聊天通知和聊天分支逻辑不参与。
- 变体、蒙版修复、局部重绘、视频和供应商原始参数不属于首个版本，后续增加时必须扩展能力契约和持久化输入快照。
