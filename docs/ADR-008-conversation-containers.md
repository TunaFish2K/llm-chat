# ADR-008: 会话容器

状态：已采纳。

Agent 的执行配置选择宿主机或本机 Docker / Podman。容器只承载会话命令和后台任务，模型请求、全局应用管理、Plugin 和 MCP 仍由现有服务负责。

容器使用 host 网络，沿用宿主机 localhost、内网、公网、DNS 和 TUN 路由。它不提供网络隔离或每会话端口空间。普通命令使用映射到服务账号的用户，允许在容器内通过 sudo 安装系统依赖。

选定目录可写挂载到 `/workdir`，修改直接落到原目录。未选择目录时使用 `dataDir/container-workspaces/<conversation-id>`。会话附件目录挂载到 `/attachments`。文件工具通过宿主机对应目录操作，维持原有路径边界检查，不必启动容器。使用附件文件工具时选择 `workspace=attachments`。

首次运行命令才创建和启动容器。同一会话内，相同引擎、镜像引用和规范工作目录复用一个环境；创建时固定镜像 ID。镜像标签更新不会替换现有环境，重置后才使用新镜像。空闲默认 15 分钟停止，工具租约和排队、运行中的后台任务阻止空闲停止。

切换配置保留旧容器并停止它，再启动目标环境。旧环境有活动工具或任务时拒绝切换。每个会话最多运行一个托管容器。容器不可用时返回错误，不改在宿主机执行。

生成快照固定环境配置，后台任务固定环境配置和 ID。旧快照按宿主机执行。取消生成保留独立后台任务；应用关闭则停止任务与容器。重启时清理容器内遗留进程，保留可写层，不恢复中断的后台进程。

工作区读写、Shell、后台任务操作和产物导出在容器模式下免审批，工具禁用规则仍有效。其他工具保留原审批策略。只读 Bubblewrap Shell 只在宿主机模式提供。容器模式下网页读取和浏览器允许 localhost、内网目标，仍保留 HTTP 协议、大小、超时及取消约束。

分叉创建独立环境，继续引用选定目录，不复制依赖层或后台任务。删除会话清理对应容器及自动工作目录，不删除用户选定目录。清理失败保留记录供后续重试。

环境可写层由容器引擎保存，独立于 SQLite。备份必须同时覆盖应用数据、选定的外置工作目录、环境镜像及创建配置，见部署手册。
