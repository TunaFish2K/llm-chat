# ADR-009：容器资源与共享安装结果

状态：已采纳。

默认容器环境使用 Alpine 3.24.1。应用下载官方 minirootfs 压缩包并通过本机 Docker／Podman 导入镜像；资源下载和软件安装由应用任务管理，不调用 Dockerfile 或构建脚本。已有运行时版本 1 的 Debian 镜像继续使用原有路径。

全局「容器资源下载」管理基础系统、必需组件、常用工具和 Plugin 软件。内置节点为 Alpine 官方、清华和中科大，默认中科大。节点只决定应用下载资源的地址，不修改会话内的软件源或网络配置。节点不可用时记录实际错误，用户可换节点重试或上传文件。

内置文件清单固定版本、架构、完整依赖和 SHA-256。`scripts/lock-container-resources.py` 仅供维护者更新清单：使用 apk 的依赖解析及官方签名验证，并生成两个架构的锁文件。它不参与应用运行或部署时的资源获取。发布前必须验证清单可在无网络环境下安装。

下载文件按 SHA-256 保存在 `dataDir/container-resources/files`，不同会话和引擎共用。下载支持续传、校验和取消；服务器忽略 Range 时从头下载。多个任务等待同一文件时共享传输，取消最后一个等待者才中断传输。上传以 8 MiB 分块保存，重新选择同一文件可继续上传。

`.llmresources` 离线包包含固定标识、单行 JSON 文件清单和依次排列的文件内容。清单只声明已知文件的 SHA-256 和长度，不携带安装脚本或宿主机解压路径。导入前必须已有对应的内置清单或 Plugin 修订。安装仅使用已校验的完整依赖；离线包不会临时联网补装。

必需组件包括 Node 24、sudo、用户管理和证书。Agent 的 `preloadResourceIds` 选择额外软件，新建 Alpine 配置默认勾选 `builtin:tools`。该包包含 npm、Python、pip、venv、Git、curl、ripgrep、Bash 和辅助命令。插件软件默认不勾选。

环境首次被生成使用时固定资源修订。首次命令缺少资源则自动下载，再在无网络的临时容器中安装并验证。安装目录仅挂载下载资源，不挂载会话工作区、附件或应用数据。验证成功后按依赖顺序保存镜像层，映射用户在会话容器启动时创建。相同软件组合在同一引擎内共用安装结果；会话各自保存后续修改。Docker 和 Podman 的镜像存储分别管理。

同一准备任务合并并发请求；不同组合在每个引擎中串行准备，共用已有依赖层。取消一次会话等待不会取消其他会话的准备任务。应用关闭会中断资源任务，重启清理本应用遗留的临时容器，保留已校验文件供重试。清理下载缓存不删除共享镜像或会话可写层。

Plugin 可以在 `plugin.json` 中声明 `containerResources`。仅包含资源的插件不需要 `entry`；工具插件接口保持兼容。软件修订随 Plugin 内容固定，更新或卸载插件不修改已经固定的环境。已存在环境优先使用自己的资源锁；修改勾选项创建或切换环境，沿用活动工具和后台任务的切换限制。插件定义的安装与验证命令只在准备容器内执行。

SQLite v45 新增资源设置、修订、任务、上传和镜像记录，并将预载选择纳入会话环境唯一键。升级不自动替换已有环境；回滚需要恢复升级前的数据备份。
